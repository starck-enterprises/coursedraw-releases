# CourseDraw releases

Public desktop builds of CourseDraw for macOS and Windows.

See [Releases](https://github.com/starck-enterprises/coursedraw-releases/releases) for the latest download.

## Install

### macOS

1. Download the `.dmg` for your Mac
2. Open it and drag CourseDraw to Applications
3. If macOS says the app is damaged:

```bash
xattr -cr /Applications/CourseDraw.app
```

Then open the app again (System Settings → Privacy & Security → Open Anyway if needed).

### Windows

1. Download the `.exe` installer
2. Run it
3. If SmartScreen appears, choose **More info** → **Run anyway**

Access is invite-only. Register with the invited email address.
